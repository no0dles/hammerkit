---
title: "Server"
description: "Run this machine as a hammerkit server that remote runs can be sent to."
---
<Callout type="warn">

Experimental. The config and the API can still change between releases.

</Callout>

`server` turns a machine into the target of remote runs. It reads its own config file, so
it needs no build file. What the config holds and how a server decides who may run what is
described in [Remote compute](/docs/remote-compute).

```bash
hammerkit server --config /etc/hammerkit/server.yaml
```

| Option | What it does |
| --- | --- |
| `-c, --config <file>` | The [server config](/docs/remote-compute#config). `HAMMERKIT_SERVER_CONFIG` can stand in for it. |

The server runs until it is interrupted. `SIGTERM` stops it gracefully, and `SIGHUP` reads
the entitlements of the config again without a restart, see
[Changing entitlements](/docs/remote-compute/entitlements#changing-entitlements).
