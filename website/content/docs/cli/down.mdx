---
title: "Down"
description: "Stop services that were started with up."
---
Stops the services of your build file, for example the ones started with
[`hammerkit up`](/docs/cli/up) or left running by `up --daemon`.

```bash
hammerkit down
```

Name services to stop only those, or tasks to stop the services they need:

```bash
hammerkit down postgres
hammerkit down dev:serve
```

Names are the ones [`hammerkit ls`](/docs/cli/ls) lists, as for
[`up`](/docs/cli/up#start-by-name). Only the services matching the
`--filter`/`--exclude` labels are stopped when those options are given. `down`
never runs a task, also not one it names.

<Callout type="info">

Pass `--env <name>` to target the services of a configured environment, for
example a Kubernetes cluster declared under `environments:`.

</Callout>

## Options

```
Usage: hammerkit down [options] [names...]

Arguments:
  names                      services to stop, or tasks whose services to stop, all when none is named

Options:
  -f, --filter <labels...>   filter task and services with labels
  -e, --exclude <labels...>  exclude task and services with labels
  --env <name>               environment
  -h, --help                 display help for command
```
