## Fixed
- **A variable set to an empty string counted as missing.** `export NAME=` and
  then a `$NAME` reference failed with `missing environment variable NAME`, so a
  CI job couldn't pass variables its provider leaves empty on some pipelines
  (a merge request id on a branch pipeline). An empty value now counts as set,
  as in a shell, and an empty process variable takes precedence over a `.env`
  file value, as a non-empty one does.
- **`cache prune` and `clean --cache` couldn't delete from registries that scope
  tokens per action**, such as GitLab's container registry: hammerkit asked for a
  `pull,push` token, and deleting failed with 401. The token request now includes
  the actions the registry's challenge names (`delete`).
